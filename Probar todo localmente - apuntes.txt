PASO 5 — Manejo de cambios de base de datos
Aquí está la clave para no perder el hilo. Cuando necesites cambiar algo en la BD:
En local — TypeORM con synchronize: true lo hace automático. Si añades una columna a una entidad, al reiniciar el backend ya aparece en la BD local.
En Supabase — Debes escribir el SQL manualmente. Por ejemplo si añades una columna:

-- Archivo: apps/backend/src/database/migration-YYYY-MM-DD-descripcion.sql
ALTER TABLE inventory_items ADD COLUMN IF NOT EXISTS peso_kg DECIMAL(8,2);
